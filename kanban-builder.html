Kanban Builder

Edit a board with structured controls that can't produce invalid syntax, see a live preview of the exact kanban.md it will write, and validate every rule of the kanban DSL — then Copy & open the GitHub editor to paste & commit. (This dashboard is a static site, so the commit itself stays in GitHub.)

Kanban DSL reference
  • Status — one of Todo, In Progress, Review, Done (chosen from a dropdown here).
  • Effort — Nd: a number then d, e.g. 3d, 0.5d (or empty).
  • Start / End — YYYY-MM-DD (or empty). End must not precede Start.
  • Task / Assignee — free text; a literal | is converted to / so it can't break the table.

Multi-section board: the form below edits the frontmatter with validated fields (no hand-typed YAML). For body sections/tables use the raw GitHub editor or the kanban-groom skill in kf-cpto (numbered list · set · delete · add).
