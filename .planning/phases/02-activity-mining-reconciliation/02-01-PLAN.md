<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local git checkout → reconcile.py | Branch names from `git for-each-ref` are untrusted text flowing into matching + terminal output |
| reconcile.py → git subprocess | Repo path / branch / ref args cross into a subprocess |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `_run_git` git subprocess calls | mitigate | Arg-list subprocess copied verbatim from repo_enum.py; never `shell=True`; never f-string a branch/repo name into a shell command |
| T-02-02 | Tampering | `_list_remote_branches` / `render_change_list` (untrusted branch text) | mitigate | Branch text is normalized to tokens for matching (no eval/exec); rendered as plain `print()` data, never executed |
| T-02-03 | Tampering | repo path passed to `_run_git` | mitigate | Use `record["local_path"]` from `repo_enum.run()` only (org-allowlist pre-validated in Phase 1); never accept a path from external input |
| T-02-04 | Information Disclosure | terminal / log output | accept | Tier-2 slice makes no authenticated calls; no secrets present in this plan's code path |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed (RESEARCH Package Legitimacy Audit: zero installs; stdlib + already-pinned `requests`/`pyyaml` only) |
</threat_model>
