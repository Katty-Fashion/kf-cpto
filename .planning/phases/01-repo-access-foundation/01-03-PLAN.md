<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repos-local/ contents → skill (read) | Cloned repo file content (kanban.md) is read and parsed; untrusted text crosses into the parser. |
| repo/branch name → subprocess argv | Enumerated names and detected branches flow into `git -C` invocations. |
| repos-local/<name> path resolution | Directory names from `iterdir()` are used to build kanban.md paths — path-traversal surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering / Elevation | `_run_git` subprocess calls | mitigate | All git calls use arg-list `subprocess.run(["git", ...])`; never `shell=True` with interpolated names — verified by static check. |
| T-03-02 | Tampering (path traversal) | `_read_kanban` path build | mitigate | Read only `repos_local / <name> / "kanban.md"` where `<name>` comes from `iterdir()` of repos-local (no user-supplied path); confirm `.exists()` before read; never follow names outside repos-local. |
| T-03-03 | Tampering (write side-effect) | kf-cpto working tree | mitigate | Phase is read-only; `_assert_kf_cpto_clean` raises if `git status --porcelain` is non-empty, and the live checkpoint confirms repos/ untouched + repos-local/ unstaged (criterion 3). |
| T-03-04 | Denial of Service | offline / fetch failure | accept | `_fetch_repo` is non-fatal (Warning + "fetch-failed", falls back to local state); the run continues (RESEARCH Pitfall 7). |
| T-03-05 | Information Disclosure | parse of untrusted kanban.md | accept | Parser is read-only text processing via the canonical utils parsers; no eval, no exec; malformed content yields warnings, not code execution. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs (stdlib + existing pyyaml; RESEARCH "No Package Legitimacy Audit Required"). |
</threat_model>
