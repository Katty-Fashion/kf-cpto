```
def _run_git(args: list[str], cwd: str | None = None, timeout: int = GIT_TIMEOUT_SECONDS) -> subprocess.CompletedProcess:
    try:
        return subprocess.run(["git"] + args, capture_output=True, text=True, cwd=cwd, timeout=timeout)
    except subprocess.TimeoutExpired:
        print(f"Warning: git {args[0] if args else ''} timed out after {timeout}s")
        return subprocess.CompletedProcess(["git"] + args, returncode=1, stdout="", stderr="git timed out")
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| skill → external tracked repo (commit + push) | Outward-facing, hard-to-reverse write to repos outside kf-cpto |
| KF_PAT → git remote URL | Secret token embedded in the HTTPS remote URL at push time |
| concurrent human edit → origin/<branch> | A competing push may diverge the remote between fetch and write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering | clobbering a concurrent human edit on origin | mitigate | _is_behind_origin fetch-then-`rev-list --count` gate aborts behind/diverged repos with [CONFLICT] before any write (WB-03); fetch failure is conservative-conflict |
| T-03-05 | Information Disclosure | KF_PAT leaking via stdout, stderr, or .git/config | mitigate | never print https_url; never call `git remote -v`; arg-list subprocess (no shell expansion); save+restore original SSH URL in a finally block; test asserts captured output has no token form |
| T-03-06 | Tampering | shell injection via repo/branch/token interpolated into a shell | mitigate | _run_git arg-list only, never shell=True; branch/repo from org-verified Phase-1 record |
| T-03-07 | Elevation/Tampering | accidental live push to a real katty-fashion repo during autonomous build | mitigate | all tests target a throwaway bare git remote (tempfile.mkdtemp); no test uses a real KF_PAT or network; SC-1 live push deferred to human UAT |
| T-03-08 | Information Disclosure | token persisting in .git/config after a failed restore | accept | Pitfall 1: finally always attempts restore; on restore failure logs [WARN] with manual-fix instruction; .git/config is local + gitignored, never committed |
</threat_model>
