# PRD B: Interactive OKF Knowledge-Graph Visualizer

## Objective

Make the OKF bundle browsable via an interactive Cytoscape.js graph on the dashboard. The aggregator emits a graph JSON from already-parsed bundle relationships; a Jekyll page renders it client-side (search, type filter, click-through).

## Context

- `scripts/okf_export.py` — extend `generate_okf_bundle` to also call a new `emit_okf_graph_json` function
- `docs/_layouts/default.html` — Mermaid loaded via `<script type="module">` from CDN; mirror for Cytoscape
- `docs/_includes/sidebar.html` — add Knowledge Graph link under Views
- `docs/dependency-graph.md` — frontmatter style reference
- `docs/_config.yml` — `docs/_data/*.json` served as `site.data`; `okf/` excluded; `_data/` is NOT excluded

## Tasks

### Task 1: Extend okf_export.py with graph JSON emitter

Add `emit_okf_graph_json(all_project_data, loe_rows, calendar_data, base_dir)` to `scripts/okf_export.py`.
Call it from `generate_okf_bundle` before returning. Output: `docs/_data/okf_graph.json`.

Node types: Project, Task, Metric, Milestone.
Edge kinds: `depends` (project -> dependency), `contains` (project -> its tasks).
URLs: Projects -> dashboard page; Tasks/Metrics/Milestones -> GitHub blob URL.
Deterministic: sort nodes by id, edges by (source, target, kind); no timestamps in JSON.

Commit: `feat(260707-p3g): add okf_graph.json emitter to okf_export.py`

### Task 2: Create Jekyll page and update sidebar

Create `docs/okf-graph.md` with Cytoscape.js graph (CDN UMD build), search input, type checkboxes, node info panel.
Update `docs/_includes/sidebar.html` to add "Knowledge Graph" link under Views.

Commit: `feat(260707-p3g): add okf-graph Jekyll page and sidebar nav link`

### Task 3: Run aggregator and commit generated JSON

Run `python scripts/aggregator.py` (or directly call the emitter logic) to produce `docs/_data/okf_graph.json`.
Verify: JSON valid, deterministic (two runs produce same output), node/edge counts printed.
Run `python scripts/validate_okf.py` — must exit 0.
Run `cd docs && bundle exec jekyll build` — must succeed; confirm built page contains Cytoscape CDN ref and container div.

Commit: `chore(260707-p3g): generate docs/_data/okf_graph.json`
