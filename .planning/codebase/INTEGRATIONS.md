# External Integrations

**Analysis Date:** 2026-06-04

## APIs & External Services

**GitHub REST API:**
- Used by `scripts/discover.py` to enumerate all repos in the `katty-fashion` org and check for `kanban.md`
- Endpoint: `GET /orgs/{org}/repos` (paginated, 100/page)
- Endpoint: `GET /repos/{org}/{repo}/contents/kanban.md` (existence check)
- Auth: Bearer token via `KF_PAT` env var (falls back to `GITHUB_TOKEN`)
- Skips archived repos; forks with `kanban.md` are valid
- Output: `repos/discovered.txt` (one `name:branch` per line)

**GitHub repository_dispatch:**
- Used by per-project repos to trigger the central aggregator when `kanban.md` changes
- Template workflow: `templates/.github/workflows/notify-kf-cpto.yml`
- Posts to `POST /repos/katty-fashion/kf-cpto/dispatches` with `event_type: kanban-updated`
- Payload carries: `project`, `ref`, `sha`
- Consumes in `aggregate.yml`: `on.repository_dispatch.types: [kanban-updated]`

**GitHub Issues API (via `gh` CLI):**
- Used by `scripts/sheets_sync.py` to file a `sync-failure` labelled issue on Sheets export failure
- Invoked via `subprocess.run(["gh", "issue", "create", ...])` — requires `GH_TOKEN` or `GITHUB_TOKEN`
- Silent on failure (no `gh` CLI or missing token does not block workflow)
- Issue body includes error traceback and workflow run URL

**Google Chat Incoming Webhook:**
- Used in two places:
  1. `aggregate.yml` step "Notify Google Chat" — posts build summary after every successful run
  2. `scripts/sheets_sync.py` `notify_chat()` — posts failure alert when Sheets export fails
- Auth: webhook URL only (no signing), stored in `GOOGLE_CHAT_WEBHOOK` secret
- Payload: `{"text": "..."}` via HTTP POST
- Silent on failure in both cases

**CDN-hosted frontend libraries (no API key):**
- Pico CSS v2: `https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.min.css`
- Mermaid v11: `https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs`
- Both loaded in `docs/_layouts/default.html` — no build step, purely client-side

## Data Storage

**Databases:**
- None. All data is file-based.

**Git Repository as Data Store:**
- `docs/_data/loe.yml` — canonical LOE data written by `scripts/aggregator.py`, read by `scripts/sheets_sync.py`
- `docs/_data/sync_status.yml` — aggregator + sheets export health metadata, read by Jekyll for dashboard badge rendering
- `docs/_data/calendar.yml` — project calendar config committed by humans, read by `scripts/auto_blocks.py`
- `repos/discovered.txt` — ephemeral list of repos; written during CI runs, excluded from git via `.gitignore`
- `docs/_projects/*.md` — per-project pages generated by `scripts/aggregator.py` and committed to master

**File Storage:**
- Local filesystem only during CI runs; no external object store
- Cloned project repos land at `repos/{repo-name}/` during CI (git-ignored, ephemeral)

**Caching:**
- None (pip packages reinstalled each CI run via `pip install ...` inline; no caching action configured)

## Authentication & Identity

**GitHub Actions:**
- `secrets.KF_PAT` — Personal Access Token with `repo` scope; used for org API calls, shallow cloning private repos, and git push back to master
- `secrets.GITHUB_TOKEN` — Standard Actions token; used only for GitHub Pages deploy via `peaceiris/actions-gh-pages@v4`

**Google Sheets:**
- Service account authentication via `google.oauth2.service_account.Credentials`
- Credentials assembled at runtime from two secrets (no JSON file on disk):
  - `GSHEET_CLIENT_EMAIL` — service account email
  - `GSHEET_PRIVATE_KEY` — RSA private key (escaped `\n` in secret, unescaped in `sheets_sync.py`)
- Scope: `https://www.googleapis.com/auth/spreadsheets` (read + write to target spreadsheet only)
- Implementation: `scripts/sheets_sync.py` `get_sheets_service()`

**No user-facing auth** — the dashboard is a public GitHub Pages site; no login required.

## Monitoring & Observability

**Error Tracking:**
- No external error tracker (Sentry, Rollbar, etc.)
- Sheets sync failures are surfaced via:
  1. GitHub Issue filed with `sync-failure` label (see `scripts/sheets_sync.py` `file_sync_failure_issue()`)
  2. Google Chat webhook notification
  3. `docs/_data/sync_status.yml` — rolling last-5 failures list
  4. Dashboard banner on `docs/index.md` (Liquid conditional on `sheets_export.last_run_status == 'failed'`)
  5. Sidebar badge in `docs/_includes/sidebar.html`

**Logs:**
- GitHub Actions job logs (stdout/stderr of Python scripts)
- `print()` statements throughout all scripts — no structured logging library

## CI/CD & Deployment

**Hosting:**
- GitHub Pages — branch `gh-pages`, published from `docs/` directory
- Base URL: `https://katty-fashion.github.io/kf-cpto/`
- Deploy action: `peaceiris/actions-gh-pages@v4` in `aggregate.yml`

**CI Pipeline:**
- GitHub Actions — `ubuntu-latest` runners
- Two workflows:
  1. `aggregate.yml` ("KF Unified Sync") — primary workflow; runs on push to master, `repository_dispatch`, weekly cron (Mon 04:00 UTC), and manual dispatch. Performs: discovery → clone → validate → aggregate → commit → Pages deploy → Sheets sync → status persist → Chat notify.
  2. `sync_to_sheets.yml` ("Sync LOE to Google Sheets") — standalone Sheets-only workflow; runs weekdays 09:00 UTC and on manual dispatch. Useful for re-syncing without a full aggregation.

**Trigger topology:**
- Per-project repos push to `kanban.md` → `notify-kf-cpto.yml` (template) → `repository_dispatch` → `aggregate.yml` in kf-cpto

## Environment Configuration

**Required secrets (GitHub repository secrets):**
- `KF_PAT` — GitHub PAT (repo scope)
- `GSHEET_ID` — Spreadsheet ID (from Google Sheets URL)
- `GSHEET_CLIENT_EMAIL` — Service account email
- `GSHEET_PRIVATE_KEY` — Service account RSA private key
- `GOOGLE_CHAT_WEBHOOK` — Google Chat space incoming webhook URL

**Optional / fallback behavior:**
- Missing `KF_PAT` / `GITHUB_TOKEN` → GitHub API calls proceed unauthenticated (very low rate limit, 60 req/h)
- Missing `GSHEET_ID` → `sheets_sync.py` prints data to stdout and exits 0 (dry-run)
- Missing Google credentials → dry-run mode, no Sheets write
- Missing `GOOGLE_CHAT_WEBHOOK` → notifications silently skipped

**Secrets location:**
- All secrets stored in GitHub repository secrets (never committed)
- `.gitignore` explicitly excludes `.env`, `credentials.json`, `token.json`, `*.pem`, `*.key`

## Webhooks & Callbacks

**Incoming (to kf-cpto):**
- `POST /repos/katty-fashion/kf-cpto/dispatches` — GitHub `repository_dispatch` event
  - Event type: `kanban-updated`
  - Source: per-project `notify-kf-cpto.yml` template workflow
  - Triggers: `aggregate.yml`

**Outgoing (from kf-cpto):**
- Google Chat space webhook — `POST $GOOGLE_CHAT_WEBHOOK` with `{"text": "..."}`
  - Called from `aggregate.yml` "Notify Google Chat" step after every run
  - Called from `scripts/sheets_sync.py` `notify_chat()` on Sheets export failure
